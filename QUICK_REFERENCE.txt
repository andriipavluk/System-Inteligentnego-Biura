GET /sensors
  └─ Returns all sensors

POST /sensors
  ├─ name: "Sensor Name"
  ├─ type: "Temperature" (or Humidity, Light, Motion, Smoke, CO2)
  └─ roomId: 1

GET /sensor-data/{sensorId}
  └─ Returns readings for sensor

POST /sensor-data
  ├─ sensorId: 1
  ├─ type: "Temperature"
  └─ value: 22.5

Add Temperature Sensor:
  curl -X POST http://localhost:5047/api/sensors \
    -H "Content-Type: application/json" \
    -d '{"name":"Living Room","type":"Temperature","roomId":1}'

Send Temperature Reading:
  curl -X POST http://localhost:5047/api/sensor-data \
    -H "Content-Type: application/json" \
    -d '{"sensorId":1,"type":"Temperature","value":22.5}'

Send High Temperature (triggers ALARM):
  curl -X POST http://localhost:5047/api/sensor-data \
    -H "Content-Type: application/json" \
    -d '{"sensorId":1,"type":"Temperature","value":31}'

Get All Sensors:
  curl http://localhost:5047/api/sensors

Get Sensor Readings:
  curl http://localhost:5047/api/sensor-data/1
