📊 WHAT EACH COMMAND DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

dotnet clean
  → Removes build artifacts from previous builds
  → Ensures clean migration process

rm -rf bin obj
  → Removes compiled binaries and intermediate files
  → Forces complete rebuild with new packages

dotnet restore
  → Downloads NuGet packages (including Npgsql)
  → Updates packages based on SmartHomeAPI.csproj

dotnet ef migrations add InitialCreate
  → Creates PostgreSQL migration files
  → Generates code for database schema in Migrations/ folder
  → Creates two files: InitialCreate.cs and InitialCreate.Designer.cs

dotnet ef database update
  → Applies migration to PostgreSQL database
  → Creates 'smarthome' database if needed
  → Creates Sensors, SensorData, __EFMigrationsHistory tables

dotnet run
  → Starts the API server
  → Listening on http://127.0.0.1:5047
  → Uses PostgreSQL from now on

ERROR: "Unable to connect to host 'localhost' on port 5432"
CAUSE: PostgreSQL not running
FIX:
  Linux: sudo systemctl start postgresql
  Windows: Start PostgreSQL service
  Mac: brew services start postgresql

ERROR: "role 'postgres' does not exist"
CAUSE: PostgreSQL user not set up
FIX:
  sudo -u postgres createuser -s postgres
  sudo -u postgres psql -c "ALTER USER postgres PASSWORD 'mojeHaslo123';"

ERROR: "database 'smarthome' does not exist"
CAUSE: Normal - will be created by 'dotnet ef database update'
FIX: Just run the command, it creates the database

ERROR: "Microsoft.EntityFrameworkCore.Sqlite still being referenced"
CAUSE: Old packages cached
FIX:
  dotnet clean
  rm -rf bin obj
  dotnet restore

ERROR: "No migrations found"
CAUSE: Migrations folder deleted correctly
FIX:
  dotnet ef migrations add InitialCreate
