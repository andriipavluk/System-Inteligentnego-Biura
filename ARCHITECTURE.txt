┌──────────────────────────────────────────────────────────────────────────────┐
│                        DATA FLOW SEQUENCE                                     │
└──────────────────────────────────────────────────────────────────────────────┘

    1️⃣  Page Load
        └─→ DOMContentLoaded event fires
            └─→ Attach form listeners
            └─→ Call fetchSensors()

    2️⃣  fetchSensors()
        └─→ GET /api/sensors
            └─→ Backend queries Sensors table
                └─→ Returns sensor list
        └─→ For each sensor:
            └─→ fetchSensorData(id)
                └─→ GET /api/sensor-data/{id}
                    └─→ Backend queries SensorData table
                        └─→ Returns readings (latest first)
        └─→ displaySensors()
            └─→ Create HTML cards
            └─→ Format values with units
            └─→ Check alarms
            └─→ Render dashboard

    3️⃣  Auto-Refresh
        └─→ setInterval(fetchSensors, 30000)
            └─→ Every 30 seconds: repeat step 2️⃣

    4️⃣  User Adds Sensor
        └─→ Fill form + submit
            └─→ addSensor() called
                └─→ POST /api/sensors
                    └─→ Backend saves to DB
                        └─→ Response with ID
        └─→ Refresh dashboard (step 2️⃣)
            └─→ New sensor appears

    5️⃣  User Sends Reading
        └─→ Fill form + submit
            └─→ sendReading() called
                └─→ POST /api/sensor-data
                    └─→ Backend saves to DB
                        └─→ Response confirmed
        └─→ Refresh dashboard (step 2️⃣)
            └─→ Value updates
            └─→ Alarm check runs
                └─→ Status updates (OK/ALARM)

    6️⃣  User Views Chart
        └─→ Click "Pokaż wykres" button
            └─→ renderChart(sensorId) called
                └─→ Gets cached sensorData
                └─→ Initializes Chart.js
                    └─→ Creates line chart
                        └─→ X-axis: timestamps
                        └─→ Y-axis: values
                        └─→ Data: all readings
